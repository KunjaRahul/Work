This program:

Defines functions to convert between Celsius, Fahrenheit, and Kelvin.
Prompts the user for a temperature value and unit (C, F, or K).
Converts the input temperature to the other two units.
Displays the results with two decimal places.
Handles the example case of 25°C, converting it to Fahrenheit (77°F) and Kelvin (298.15K).
Includes error handling for invalid inputs.
